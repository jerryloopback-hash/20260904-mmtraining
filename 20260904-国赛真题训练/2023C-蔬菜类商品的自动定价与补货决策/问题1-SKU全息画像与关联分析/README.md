# 2023C 问题 1：蔬菜单品全息画像与关联分析

2023 高教社杯 C 题《蔬菜类商品的自动定价与补货决策》问题 1 的完整方案：在品类层面的常规分析之外，给 246 个有销售单品建立了统一画像，用四套互补的分层体系刻画分布规律，并用归因分解、共现网络与互信息重新检验了品类间与单品间的关系。

## 运行方法

环境：Python 3.10+，依赖 pandas、numpy、matplotlib、seaborn、scikit-learn、networkx（≥2.8，Louvain 用内置 `community.louvain_communities`）。

按顺序运行：

```bash
python code/00_数据清洗.py    # 需要与附件1~4.xlsx 同目录，产出 data_clean/
python code/04_问题1_升级_SKU全息画像与分层.py
python code/05_问题1_升级_相关归因与共现网络.py
```

脚本默认在项目根目录（本题目录）运行，中间缓存读写 `data_clean/`，图片输出到 `figs/`。04、05 两个脚本优先读取 `data_clean/附件2_销售流水_clean.pkl` 缓存。

## 核心结论（详见报告）

1. 分布高度长尾：28 个 A 类单品贡献销售额 69.27%，24 个热销单品贡献 47.42% 销量。
2. 花叶类均价最低（相对价格指数 0.76）但毛利率 31.18% 居第一梯队，毛利由损耗率与周转决定。
3. 熵权-TOPSIS 四梯队中，广度（动销率）权重最高（0.2928），得分与总销量 ρ=0.527，分层不等于按销量排队。
4. 茄类是唯一夏菜（季节重心 6.1 月），与冬菜的表面低相关 0.074~0.257 在去季节后恢复到 0.30~0.40，品类联动真实存在。
5. 共现网络 122 节点、1,990 边，3 个跨品类社团（Q=0.3983），关联结构由购物篮组合决定。
6. 36 组同款不同包装中 23 组散装对份装 lift<1（替代），菌菇盒袋装 lift 2.18~4.52（互补）。
7. 30 单品推荐池覆盖销量 60.6%、毛利 63.3%，货位周转最慢 1.79 天，可直接作为问题 3 初始解。
