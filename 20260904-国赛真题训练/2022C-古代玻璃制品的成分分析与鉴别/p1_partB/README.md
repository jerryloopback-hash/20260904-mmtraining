## 核心结论速览

- **统计规律**（两类玻璃风化方向相反）：高钾玻璃风化 = K2O(-94.3%)、MgO、Al2O3、P2O5 等可溶组分流失，SiO2 被动富集(+36.3%)；铅钡玻璃风化 = SiO2 骨架流失(-53.9%)，PbO(+98.8%)、P2O5(+398.9%)、CaO(+108.8%) 升高。全部经 FDR 校正与 CLR 敏感性验证。
- **风化程度指数**：连续指数（0=风化前均值，1=一般风化均值），经 PC1 对照/留一排序/噪声地板三重检查；"严重风化点"标签反映取样部位，与成分偏移幅度相关但不等价；显著成分沿程度单调渐变（剂量-反应）。
- **成分还原**：主模型（分位数配对+Theil-Sen）与对照模型（均值比例缩放）还原 32 个风化点，留一验证 MAE 2.20 / 1.51 个百分点，附 bootstrap 90% 区间。
